# Wonderful Montessori Preschool LLC

Website for Wonderful Montessori Preschool — Montessori preschool, Pre-K and daycare for ages 3–6 in Hayward, CA.

## Publish on GitHub Pages
1. Create a new repository on GitHub and upload every file in this folder (all in one place — no subfolders).
2. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Your site will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

## Tour request emails
Tour requests are emailed to **Haywardpreschool@gmail.com** via FormSubmit.
After the site is live, submit one test request, then click the **"Activate form"** link FormSubmit sends to that inbox (check spam). All later requests arrive automatically.
